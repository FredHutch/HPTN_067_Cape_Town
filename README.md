# HPTN_067_Cape_Town
Code repository for manuscript: ESTIMATED BENEFITS OF PROVIDING ON-DEMAND PRE-EXPOSURE PROPHYLAXIS OPTIONS FOR CISGENDER WOMEN IN SOUTH AFRICA: A MODELING STUDY       

Sarah E. Stansfield, Mia Moore, Marie-Claude Boily, James P. Hughes, Deborah Donnell, Linda-Gail Bekker, Dobromir T. Dimitrov           

Run this simulation in RunSim_Capetown.R           
All other R files are called within this file          

Data for the HPTN 067 Cape Town trial can be found here: https://dataverse.harvard.edu/dataverse/HPTN067/              
For questions or help in formatting data to use this code, email sstansfi (at) fredhutch (.) org
